# Bioestimulación · Medicina Molecular y Regenerativa

Sitio web oficial para la clínica de medicina molecular y regenerativa **Bioestimulación Montevideo**, dirigida por el **Dr. Emmanuel de Souza Leal**.

## Características
- **Pantalla de Bienvenida / Intro:** Animación de carga líquida simultánea en el ADN y el nombre Bioestimulación.
- **Microinteracciones:** Scroll parallax dinámico, rotación del ADN en tiempo real, tracker lateral de secciones y efectos 3D tilt en tarjetas.
- **Tratamientos Médicos:** Filtros interactivos por categoría (Facial, Capilar, Corporal & Láser) con modal de detalle.
- **Casos Clínicos Reales:** Deslizador interactivo de comparación Antes y Después.
- **Widget de WhatsApp:** Botón flotante con globo de chat interactivo y respuestas rápidas directas a la clínica (+598 92 374 367).

## Estructura del Proyecto
```
bioestimulacion/
├── index.html        # Estructura principal de la web
├── css/
│   └── style.css     # Estilos, efectos 3D y animaciones
├── js/
│   └── main.js       # Dinámicas de scroll, intro y sliders
├── assets/
│   └── img/          # Imágenes de la clínica y tratamientos
├── server.js         # Servidor local Node.js (opcional)
└── README.md
```

## Ejecución Local
Podés abrir `index.html` directamente en tu navegador o ejecutar el servidor local con:
```bash
node server.js
```
El sitio estará disponible en `http://localhost:8080`.
